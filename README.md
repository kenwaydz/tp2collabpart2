# tp2collabpart2# Simple Calculator

## 1. Project Description

This project is a simple calculator developed
using Python as part of TP 02.

It demonstrates collaborative development
using Git and GitHub.

## 2. Features

The calculator supports four operations:

- Addition
- Subtraction
- Multiplication
- Division

It also handles division by zero.

## 3. Technologies Used

- Python 3
- Git
- GitHub
- Visual Studio Code

## 4. Team Members

- Member 1: Addition and Subtraction and Documentation
- Member 2: Multiplication and Division
- Member 3: Main Menu 

## 5. Project Structure

- main.py: Main calculator interface
- addition_subtraction.py: Addition and subtraction
- multiplication_division.py: Multiplication and division
- README.md: Project documentation

## 6. How to Run

1. Install Python 3.
2. Clone the repository.
3. Open the project folder.
4. Run the following command:

python main.py
